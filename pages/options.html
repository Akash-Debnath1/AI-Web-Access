Search engines

Pick the engine used first. If it fails or returns nothing, the engines below it are tried in order (when auto-fallback is on). No API key is needed for any built-in engine.

Auto-fallbackTry the next engine automatically when one fails.

Optional API-key engines (strongest, most reliable)

These are off by default and never needed. If you add a key, that engine becomes available and is tried first.

Fallback order

Drag is not required — use the arrows. Engines you switch off are skipped.

    Custom search engines & servers

    Point AI Web Access at any search engine or your own server. Use {query} where the search term goes and {count} for the number of results. For HTML pages give CSS selectors; for JSON APIs give the field names.

      Dark web (.onion) — Tor mode
      
      
      
        .onion addresses exist only inside the Tor network, so a browser extension
        cannot open them by itself. When you turn Tor mode on and run Tor on this computer
        (install tor, or use Tor Browser's bundled daemon), the extension installs a
        scoped proxy rule that sends only *.onion traffic to your local Tor SOCKS
        port. All normal browsing stays direct. Onion search engines are then usable as regular engines.
        Onion services use plain http:// (no public CA issues .onion certificates), which is
        normal and still end-to-end encrypted by Tor itself.
        The Test button auto-tries ports 9050 → 9150 → 9051 and saves whichever works.

      Onion search engines
      
      
      Shipped: DuckDuckGo (.onion) and Ahmia (.onion). Onion addresses
        sometimes rotate — if one stops resolving, add the current address yourself as a
        Custom engine (type HTML) using a trusted directory. Tor clients discover relays
        automatically via the directory authorities; no node list is needed or bundled.
      
      
      

      
      
        
      What is deliberately NOT included: marketplaces,
        torrent trackers / pirate servers, or any service whose purpose is illegal distribution.
        This extension indexes and searches; it does not bundle infringement infrastructure.

            About & shortcuts
            
      
            
        
            AI Web Access gives any AI chatbot real-time knowledge of the web.
        Before your message is sent, it searches the web with the engine you chose, attaches the
        freshest results (with sources), and — if you like — reads the actual pages. It also adds
        hands-free voice dictation using your browser's own speech engine.
            
        
            Everything runs locally in your browser plus the search engines you pick. Your prompts are
        sent to the search engine as a query and the results are sent to the chatbot you are using.
            
      
            
      
            Keyboard shortcuts
            
      
            
        
            Alt+Shift+WToggle web access on / off
            
        
            Alt+Shift+MCollapse / expand the floating panel
            
        
            Alt+Shift+VStart / stop voice dictation
            
      
            
      
            You can change these on Chrome's extensions shortcuts page
        (chrome://extensions/shortcuts).
